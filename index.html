Drop the .syx you are about to flash on a Model:Samples (for example, the Model:Cycles OS with mods). It checks that only the OS changes and that Elektron's bootstrap and startup menu, your recovery path, stay untouched.

Everything runs in your browser. The file is never uploaded.

What is checked, and why

An OS update for the Model:Samples is a SysEx stream carrying an ELE3 container with four sections: meta (5), bootstrap (2, holds the STARTUP MENU), MAIN OS (3) and updater (4), signed with HMAC-SHA256. A custom OS should replace section 3 only.

  • SysEx transport: start/end markers, packet count, sequence, every packet checksum, no stray bytes. Product 0x0F is the Samples' own transport. Product 0x11 is the transport for a Samples that already runs a Cycles OS installed for it.
  • Container: content checksum, header and section table identical to the official Model:Samples OS 1.13, the same load addresses and bootstrap version, a valid layout, and a container small enough for flash (≤ 0x1c0000 bytes from 0x20000).
  • Protected sections: bootstrap, updater and meta are compared with fingerprints of Elektron's own. A changed bootstrap is the one thing that can brick the device, so it is never accepted.
  • Signature: valid with the Model:Samples key, which is derived from the file's own verified bootstrap. Otherwise the device refuses the file ("Upgrade Failed") and writes nothing.
  • MAIN OS: unpacks without error. When the bootstrap unpacks it in place (input at 0x40200000, output from 0x40000400), the output never overtakes unread input. For a Model:Cycles OS, the update-check code must be intact and the 32-byte key fix must be present, so the official Samples OS can come back over USB.

If an OS ever fails to boot, the STARTUP MENU still works: hold FUNC while powering on, press TRIG 4 (OS UPGRADE), and send the official model-samples_OS1.13.syx to the MIDI IN through a MIDI interface. USB does not work in that menu.

The page stores no Elektron firmware bytes and no key, only SHA-256 fingerprints of the official OS 1.13 parts. Format and rules come from Modded-Cycles (mtlib, mods_for_samples.py, notes 02/41/57) and the in-place boot layout from Supermodel (notes/41 §9).

Bring a Model:Samples that runs a Model:Cycles OS back to its own Model:Samples OS over USB. These are the two ways back from 18nelli18's Modded-Cycles flasher. The files are built in your browser from your official OS files and must match Modded-Cycles' reference builds byte for byte.

Before you start: back up your projects and samples with Elektron Transfer. Set every track that uses an added machine (7 and up) back to one of the six original machines. Close Elektron Transfer and Overbridge so this page can use the USB port.
